## Critical seam decision: polyphony CLI verb error emission

**Problem:** Polyphony verbs exit 0 always. `on_error:` routes never fire for verb failures today.

**Recommendation:** Option C (hybrid) — domain outcomes (skip, invalid) remain exit-0 + JSON routing; infrastructure failures only exit non-zero + `$CONDUCTOR_ERROR_OUT`.

**Implementation cost:** Low (one try/catch in verb host). **No breaking changes** to existing routes.
